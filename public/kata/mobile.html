─── mobile principles ───────────────────────────
tap target
Mọi nút ≥ 44×44px (status dot 44px hit-area dù visible 12px). Cards có tap-affordance border.
filter → sheet
Desktop dropdowns chuyển thành bottom sheets. Filter button trên top bar mở sheet với options.
bottom tab nav
5 tabs cố định: home / servers / logs / cost / more. "more" chứa playground, settings, đăng xuất.
image-forward logs
Image/video logs có thumbnail to full-width (4:3). NSFW block có placeholder X icon, prompt hidden.
⌘K → fab
Command palette không khả dụng. Search bar visible trên list pages. Hamburger mở drawer nav.
three.js · off
Ambient three.js disabled trên mobile (performance + battery). Chỉ giữ radial gradient + grain.
density · 4px grid
KPI cards 2×2 thay vì 5×1. Charts compact heights (80-120px). Recent activity tối đa 4 items inline.
live indicator
Pulse dot trong top bar khi WebSocket connected. Pause toggle trong long-running pages (logs).
feature parity check
overview · logs · cost · settings · playgroundfull
3-section servers list (managed / invite / member)full
live activity stream + nsfw blocked rowsfull
cost donut + 30d chartcompact
command palette ⌘Kdrawer + search
three.js ambientdisabled
implementation note · phase 15
Trong Next.js 14, dùng useMediaQuery('(max-width: 768px)') như parent `MobileShell.jsx` để switch shell. Bottom tab bar dùng shadcn <Tabs> hoặc custom với framer-motion spring transitions. Bottom sheets dùng vaul (drawer lib chuyên cho mobile). Safe-area: env(safe-area-inset-bottom) trên tabbar padding.
